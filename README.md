## 🎯 What is Skin-Swapper-Valorant?

Skin-Swapper-Valorant is a lightweight Windows application designed to modify the visual appearance of your in-game weapons. Unlike other tools that may be clunky or complicated, our program focuses on **simplicity, speed, and reliability**.

The application works by safely interacting with Valorant's memory to change skin IDs, allowing you to equip skins you don't own for your own viewing pleasure. **Please note:** This is a client-side visual change only — other players will not see the skins you've applied.

## 🚀 How to Use

1.  **Launch the application** from your desktop or start menu.
2.  **Log in** with your Riot Games credentials. (Your credentials are processed locally and securely — no data is ever sent to external servers.)
3.  **Browse the skin catalog** by weapon type (Vandal, Phantom, Operator, etc.) or by collection name.

- If a skin doesn't appear, try restarting Valorant and reapplying.

## 🚧 Troubleshooting

### "Application is blocked by Windows Defender"
- This is a common false positive due to the way the application interacts with game memory.
- Add the application folder to your antivirus exclusion list.
- Temporarily disable real-time protection during installation only.

### Installation Fails
- Make sure you are running the installer **as Administrator**.
- Verify that your internet connection is stable.
- Ensure you have enough disk space (at least 200 MB free).

### "Password is incorrect" When Extracting
- Ensure you are using the password exactly as provided: `2026` (case-sensitive).
- Try using 7-Zip instead of WinRAR if you continue to experience issues.

### Skins Not Showing in Game
- Make sure Valorant is fully closed before applying skins.
- Try running the application as Administrator.
- Check that you are using the latest version of the tool.

### Application Crashes or Freezes
- Restart the application and try again.
- Update your graphics drivers.
- Disable any overlay applications (Discord, NVIDIA GeForce Experience, etc.) temporarily.
